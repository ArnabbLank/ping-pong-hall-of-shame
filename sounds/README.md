# Custom win and lose sounds (optional)

1. Drop short audio files here (mp3, ogg or wav; under 6 seconds plays in full).
2. List them in `config.js`:
   ```js
   sounds: { win: ["sounds/win-1.mp3"], lose: ["sounds/lose-1.mp3"] }
   ```
3. Reload. A win or loss plays one of your clips about 3 times out of 4, otherwise a built-in synth sound.

Only add clips you have the right to use. This repo is public, so anything committed here is public too. If you only want them on your own machine, keep the files uncommitted.
